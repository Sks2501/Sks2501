# Engineering Contribution Standard

This profile repository is maintained as a technical index rather than a personal biography.

## Content rules
Changes should emphasize systems engineering, architecture, protocol design, software quality and public technical work. Do not add precise location, private contact data, personal identifiers, credentials, internal infrastructure details or production secrets.

## Engineering claims
Technical claims should be backed by public code, specifications, tests, reproducible examples or clearly marked research/prototype status. Avoid presenting speculative or incomplete work as production capability.

## Repository references
Only link repositories that are intentionally public. Public examples must use synthetic data and non-production interfaces.

## Review gate
Before merging, verify:

- no personal/private information was introduced;
- no credentials or production endpoints are present;
- technical descriptions match repository contents;
- links resolve correctly;
- security boundaries are stated where relevant.
